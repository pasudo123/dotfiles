# 에이전트 운영 규칙 (Governance)

## SSoT 원칙
- 에이전트 규칙/템플릿 문서는 `docs/agents/`에서만 관리한다.
- 루트 디렉토리에 규칙 문서를 파편화해서 만들지 않는다.
- 새 규칙이 필요하면 `docs/agents/`에 추가하고 `Agents.md`에 링크한다.

## 문서 역할 분리
- `workflow.md`: 브랜치/PR/머지 이후 정리 흐름
- `pr-guidelines.md`: PR 본문 작성 규칙
- `pr-template.md`: PR 본문 템플릿
- `release-template.md`: 릴리즈 노트 템플릿

## 유지보수 규칙
- 문서 간 중복 설명을 최소화한다.
- 규칙 변경 시 관련 문서 링크를 함께 점검한다.
- 인덱스(`Agents.md`)는 링크 중심으로 짧게 유지한다.
